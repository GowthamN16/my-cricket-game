# 🏏 3D Browser Cricket Game

A 3D browser cricket game built with HTML, CSS and JavaScript.

## 🎮 Play the Game

Visit the live game:

(https://github.com/GowthamN16/my-cricket-game)

## ✨ Features

- 3D cricket gameplay
- Batsman, bowler and wicket-keeper roles
- Career mode
- Pause menu
- Mobile-friendly controls
- Runs directly in the browser

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Three.js

## 📱 Compatibility

Works in modern web browsers on desktop and mobile devices.
